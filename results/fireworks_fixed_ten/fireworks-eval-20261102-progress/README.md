# Fireworks evaluation progress snapshot

This is an explicitly published, incomplete snapshot of the live Fireworks run.

It contains 50 saved model/task records out of 50 planned records.
The live run continues separately; this snapshot is stable. Read `summary.json`
for per-arm completion and service-error counts, `all_results.txt` for English
outputs, and `failed_request_history.json` for archived failures that were retried.
The key is never included. Scores use the shared local evaluator; these hosted
models are alternatives to the Modal Qwen checkpoints, not identical models.
